# Algorand DApp

This is a React-based decentralized application that connects to the Algorand TestNet using AlgoSigner.

## Features
- Wallet connection with AlgoSigner
- Interact with Algorand TestNet
- Simple front-end UI

## Getting Started
1. git clone https://github.com/Aftab-2004/Dapp.git
2. npm install
3. npm start
